CHONGZHILIN.MY — SEO-READY WEBSITE PACKAGE
===========================================

This package contains the full website plus technical SEO improvements:
- Unique title and meta description for every page
- Canonical URLs on chongzhilin.my
- Index/follow robots metadata
- Open Graph and Twitter sharing metadata
- Schema.org structured data for the academic profile
- robots.txt
- sitemap.xml
- Clean internal links to the canonical page URLs

DEPLOYMENT
1. Upload/deploy the complete contents of this ZIP to the same Cloudflare Worker/site.
2. Confirm these URLs load:
   https://chongzhilin.my/
   https://chongzhilin.my/research
   https://chongzhilin.my/publications
   https://chongzhilin.my/teaching-service
   https://chongzhilin.my/robots.txt
   https://chongzhilin.my/sitemap.xml

GOOGLE SEARCH CONSOLE
1. Add a Domain property for: chongzhilin.my
2. Verify ownership with the TXT DNS record Google gives you.
3. In Search Console > Sitemaps, submit: sitemap.xml
4. In URL Inspection, inspect https://chongzhilin.my/ and click Request indexing.
5. Repeat for /research, /publications and /teaching-service.

IMPORTANT
SEO metadata helps Google understand the site, but indexing is not instant and rankings are not guaranteed.
